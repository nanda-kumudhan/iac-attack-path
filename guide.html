PROJECT GUIDE / v0.1

Offline infrastructure review

Compare base and head Terraform plans to find newly introduced routes from the internet to AWS data. The parser, typed graph, path search, IAM subset, canonical diff and minimum-edit solver run in the CLI, GitHub Action and this browser.

Analyze in the browser

  1. Export both plans using terraform show -json.
  2. Choose a base and head file in Path review. Base is optional and defaults to empty infrastructure.
  3. Select Analyze plans. A cancellable worker performs analysis locally.
  4. Inspect the chain, evidence, assumptions and complete minimum edit set. Export JSON, Markdown or SARIF as needed.

Each plan is limited to 50 MiB. You can also open a precomputed v1 report up to 5 MiB. Load demo analyzes a normalized CloudGoat SSRF slice and clearly marks it as an example.

Use the CLI

npm ci
npm run analyze -- --base base.json --head head.json
npm run dev
npm run check
npm run evaluate
npm run benchmark

The CLI exits 0 for no introduced paths, 1 for introduced paths including possible ones, and 2 for invalid or incomplete analysis. It writes JSON, Markdown, SARIF and the head graph. The Action accepts base-plan and head-plan directly and writes reports before failing the gate.

What a finding means

The main chain is Internet → SecurityGroup → Instance → Role → Bucket. Public ingress is combined with public-address and routing evidence. Credential use explicitly assumes an application exploit, SSRF or another compromise. Any uncertain edge makes the chain possible. A possible path is still reviewable and fails the gate by default.

IAM support includes role policies, object-read grants, a limited deny/boundary evaluator, role assumption and four escalation rules: self PutRolePolicy, self AttachRolePolicy, CreatePolicyVersion on an attached customer policy, and UpdateAssumeRolePolicy with AssumeRole. This is a subset of AWS behavior.

Minimum blocking changes

Each supported rule, IAM statement or profile edit costs one. Max-flow/min-cut seeds an exact shared-edit search that returns the smallest edit set intersecting all introduced paths. A cut with cost greater than one needs every listed edit. Minimality applies to this finite supported model, not business disruption or every possible AWS remediation. No HCL is rewritten automatically.

These adapted slices do not establish full-lab accuracy. Source revisions, normalization, machine-readable results and sparse 500/5,000-resource benchmarks are in the repository.

Privacy and limits

Scripts, styles and Cytoscape are bundled locally. There is no backend, CDN or analytics, and the production content security policy blocks network connections. Selected files stay in browser memory. Clearing/cancelling terminates active analysis. The initial site assets must still be downloaded or served once.

AWS only. Full IAM, SCPs/RCPs, KMS, NACLs, load balancers, arbitrary public CIDRs, Kubernetes and Azure are outside this release. Missing links may cause misses; external controls may cause false positives. An empty report does not prove security. Search limits produce an error, not a clean verdict.

CloudGoat and TerraGoat were inspected statically. Nothing was deployed. The separate Terraform example uses placeholder credentials and was only planned. No AI or ML is used.
